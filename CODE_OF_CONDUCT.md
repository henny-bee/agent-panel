# Code of Conduct

Agent Panel follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Harassment, insults and bad-faith participation are not welcome.

The maintainer, henny-bee, may warn, restrict or ban anyone who makes the project worse for others.

Report conduct issues to the maintainer on GitHub. For anything you'd rather not post in public, use the private report described in [SECURITY.md](SECURITY.md).
